When you drag a file or folder from your Mac onto a chat's message box, Paseo normally uploads it to the daemon. With large files or whole folders that takes a long time. This plugin skips the upload and writes the item's local path into the message, so the agent reads it straight from disk.

It works in the desktop app, with one or several items dropped together. Paths that contain spaces are wrapped in double quotes. The terminal, the file explorer and the file view keep their normal drop behavior. If Paseo cannot resolve the path of a dropped item, the plugin does nothing and the usual upload happens.

The inserted path is the one on the computer running the app. If the chat runs on another host, such as a remote server, that path does not exist there and the agent cannot open it. The plugin never reads or sends file contents: it only uses the path. It finds the message box through the app's page structure, so a Paseo update that changes that structure can stop it from inserting text.
